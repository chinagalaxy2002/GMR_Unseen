# Algorithm overview

Seen Guard protects familiar-query ranking while retaining DEC for queries absent from the positive-training combination inventory. The upper layer freezes train-reference CDFs, the query inventory and a policy selected on Seen validation; the lower layer performs query-text-only routing and applies the frozen policy. Covered queries use a calibrated detector/DEC fusion, an FRR-constrained Baseline threshold, or a DEC decision-preserving within-group re-ranking; uncovered queries retain DEC ranking and decisions after a positive affine mapping. Every final score uses the common threshold zero and accepted predictions keep their original native localization window. FRR denotes the positive false rejection rate; G and F denote G-mIoU and rejection F1.

The covered/uncovered switch is inferred from query text and train statistics, not supplied Seen/Unseen annotations. On this benchmark it exactly matches those partitions because it uses the same canonicalization rules as dataset construction; independent data are required before claiming general routing accuracy. This is an explicit threshold-protocol variant, and there are no newly trained weights. Validation-calibrated hyperparameters, empirical distributions and a fixed pretrained text parser are still required.
