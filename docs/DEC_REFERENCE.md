# DEC 幂律乘积门控：算法与评估边界

本发布包将被审计的 DEC 版本命名为 **DEC-Power-CDF**。它是固定规则的免训练后处理器，用于抑制存在性检测器的高分假阳性。没有新训练的神经网络、MoE、可学习路由或自适应指数。结果对应训练集参考 CDF 的修正版，不对应旧的测试集排序版本。

## 输入和证据

每条样本提供查询、backbone 存在性分数及预先缓存的多模态标量。以下列索引沿用历史缓存：

| 列 | 本方法使用的内容 |
|---|---|
| 0 | FlashVTG 历史存在性原始分数（数值可超出 0–1） |
| 1 | Moment-DETR 历史保存的存在性概率 |
| 2 | QD-DETR 历史保存的存在性概率 |
| 3 | CLIP 全局场景与整句查询相似度 |
| 5 | CLIP 峰值帧视觉显著性 |
| 6 | CLIP 候选窗口与分解后的物体短语对齐 |
| 8 | SlowFast 候选窗口相对全视频的速度对比 |
| 12 | 有符号动作状态变化：视频片段首尾特征差与动作短语的投影 |

其余缓存列保留以维持原始 14 维输入格式，但 DEC 不读取它们。第 3 列的源码定义是全局场景相似度，不能将其称为已经独立验证的交互特征。

## 固定查询路由

查询转小写后按以下顺序做字符串子串匹配，并非词元匹配。先匹配的分支优先：

1. 含 `run / walk / slow / fast`：
   `E = 0.50 X[5] + 0.35 X[8] + 0.15 X[12]`。
2. 否则含 `chair / couch / bed / sofa / box / cabinet / shelf / table / cup / book`：
   `E = 0.45 X[5] + 0.35 X[6] + 0.20 X[3]`。
3. 否则：
   `E = 0.55 X[5] + 0.30 X[3] + 0.15 X[12]`。

因此该方法并未完全剔除静态场景和物体通道。路由词表、权重、指数固定，当前结果不能证明这些参数只在 Seen 数据上设计。

## 训练参考 CDF 与融合

每个划分只用其 Seen 训练样本建立两个参考分布：backbone 检测器分数 d 和路由证据 E。对参考数组 R 及新值 x，采用保留并列的中点经验 CDF：

`F_R(x) = (# {r < x} + # {r ≤ x}) / (2 |R|)`。

训练参考一旦拟合，固定用于验证和测试；不使用测试标签或测试批次重排。最终分数：

`S_DEC = F_detector(d)^0.65 × F_evidence(E)^0.85`。

低证据秩会降低乘积，允许证据约束检测器的高分。这是一种软合取排序，不是动作是否真实发生的因果证明。CDF 输出是相对秩，未经概率校准；不能将 S_DEC 称为发生概率。指数小于 1，乘积也不保证小于两项未经指数变换的原始秩。

Baseline 直接使用同一缓存的原始 backbone 分数 d。二者共享标签、样本、窗口和评估协议，因此对照只改变存在性打分与对应的验证阈值。

## 阈值、定位与统计

分别对每个 backbone、每个划分、每个方法在 Seen 验证集上选择阈值。候选是分数的第 5 到 95 百分位，共 91 个；选 Balanced Accuracy 最大者，平局取最先出现的候选。不是全部唯一分数上的精确最优阈值。测试中 `score >= threshold` 接受。

定位使用各 backbone 历史提交中的第一个合法窗口。DEC 不修改窗口坐标，拒绝时将预测置空。对一个预测窗口和多个真值窗口，G-mIoU@1 的集合 IoU 是最佳匹配 IoU 除以真值窗口数；两者均空为 1，恰有一者空为 0。所有查询等权平均。

Seen / Unseen AUROC 分别在 S+/S− 和 U+/U− 上计算。Rej-F1 以拒绝负例为正类；RR 为全体拒绝率；S+ FRR、U+ FRR 为对应正例的误拒率。每个指标的五划分结果都采用等权算术平均，不是把样本合并重新计算。

置信区间使用 2,000 次视频聚类配对 bootstrap，seed=3407。每次从五划分视频的并集中有放回抽取同样数量的视频，各划分和两个方法共用视频计数，保留跨划分相关性。固定 CDF 和阈值，用 2.5/97.5 百分位得到差值区间；若任一 AUROC 子集缺少类别，整次抽样丢弃。本次 2,000 次均有效。区间不覆盖重新训练、参数选择或特征提取的不确定性。

## 历史结果的修正及实际代价

旧版本通过 `argsort(argsort(x))` 强行拆开并列，并在测试批次上重新排序。其历史 QD-DETR Unseen AUROC 0.6332 不属于本发布版本；修正版为 0.6086。两者不能混用。本表所有点估计均重新从冻结输入计算，不能用 bootstrap 差值均值替代原样本点估计。

修正版的五划分宏平均 Unseen AUROC 分别为 Moment-DETR 0.6122、QD-DETR 0.6086、FlashVTG 0.6200。但 Seen AUROC 分别下降约 3.38、2.14、5.19 pp，正例误拒率也上升。部分划分的 G-mIoU/Rej-F1 有下降，且 A1/A2_alt 的 Unseen AUROC 仍低于 0.60。宏平均改善不表示所有划分均达标。

多模态证据缓存来自共享 HQ 候选窗口，不是每个 backbone 独立提取的本地证据；定位窗口则各用自身原始提交。这些是历史探索结果，无法排除方法选择过程中已知 Unseen 结果的影响。需要独立新留出集和各 backbone 自有证据验证后再作更强泛化结论。

本分支提供冻结输入的算法与评测复现，包含真实历史 backbone 分数和窗口。它不包含原始视频编码、特征重新提取、backbone 训练或检查点；不能据此宣称从原始视频端到端复训已被复现。
