# 交付实验核验（2026-10-07）

## 结论

阈值评估、机制消融和完整 2,000 次 Bootstrap 脚本均已重跑，与交付日志显示值一致。训练参考 CDF、Seen 验证选阈值的基本实现符合所述评估路径；核对了五划分 train/Seen-val/test 的 QID 顺序、标签、视频对应，目标骨干定位预测无缺失。

但是，指标范围、部分逐划分数据和消融名称有问题。现有缓存上 Unseen 排序及固定阈值拒绝有改善；收益伴随 Seen 排序损失以及部分正例误拒增加。尚未完成原始 logit、公平自身候选、新语义冻结评估及操作指标差值显著性证明。

## 1. RR 与 Rej-F1 的真正规则

`run_thresholded_gmr_eval.py:125`：`rr=(tn+fn)/len(y_te)`。

这统计所有查询的总体拒绝比例，包含正确拒绝负查询和错误拒绝正查询，不是 U− 的正确拒绝率。正确负例拒绝率应为 `tn/(tn+fp)`，且需先选取 U−。

同文件 117–124 行的 Rej-F1 公式本身正确，正类为无对应时刻查询；但当前是在完整测试集 S+/S−/U+/U− 上算，再对五划分取均值。G-mIoU@1 同样是 All。因此此前 RR 与 F1 上界不一致的现象源于 RR 定义不同，并非已证实 F1 公式算错。

按原脚本相同阈值重新分组，Unseen 指标如下（%，五划分等权）：

| 骨干 | 分支 | Unseen Rej-F1 | U− 正确拒绝率 | U+ 误拒率 |
|---|---|---:|---:|---:|
| Moment-DETR | Baseline | 35.10 | 31.96 | 29.71 |
| Moment-DETR | 加权和 | 46.76 | 38.73 | 28.15 |
| Moment-DETR | 幂律 | 62.25 | 56.09 | 42.41 |
| QD-DETR | Baseline | 28.51 | 21.47 | 18.76 |
| QD-DETR | 加权和 | 44.78 | 36.93 | 27.79 |
| QD-DETR | 幂律 | 58.25 | 49.47 | 35.55 |
| FlashVTG | Baseline | 33.42 | 27.04 | 21.85 |
| FlashVTG | 加权和 | 48.15 | 40.90 | 28.01 |
| FlashVTG | 幂律 | 57.95 | 49.13 | 35.41 |

所以不能由 All Rej-F1 的小幅下降推断 Unseen Rej-F1 没有改善；也不能忽略正例误拒增幅。以上新分组结果还没有操作指标的置信区间。

## 2. 阈值搜索不是精确全局最大

阈值确实只使用 Seen 验证标签。`find_best_threshold` 只检查分数第 5–95 百分位的 91 个候选，返回网格上的最大 Balanced Accuracy；不是枚举所有决策边界的精确最大值。并列时保留最先访问的候选。论文应说明搜索网格与接受规则 `score>=tau`，且保存每划分阈值、混淆矩阵。

## 3. 消融归因混杂

- 去路由版本统一使用 `.4 peak+.3 global+.3 velocity`；除了不分流，还删除物体对齐、方向特征并改变权重。只能认定该统一配置较差，不能隔离“路由本身是唯一有效机制”。
- 去方向并非把原始 12/13 列直接置零：代码把动作方向的 0.15 权重重新分给 peak。原模型并未使用列 13。因此应命名为“方向项替换为 peak”，另补严格置零与公平重调权重对照。

## 4. 交付文档逐划分数据错误

文档宏平均与新脚本一致，但逐划分表不是同一协议的完整结果；Power 部分保留旧测试集排名数值，加权和部分也不对应现有脚本。举例：

| 条目 | 文档 | 冻结训练 CDF 实际复算 |
|---|---:|---:|
| QD A2_alt Power Unseen | 0.6435 | 0.5406 |
| QD A2_alt WSum Unseen | 0.6012 | 0.5262 |
| Moment A1 WSum Seen | 0.7712 | 0.7828 |
| Moment A3 WSum Unseen | 0.6120 | 0.6225 |

精确逐划分值见 `audit.json` 的 `split_auroc`。应从机器结果自动生成表格，不能混用旧排名与训练参考 CDF。

## 5. Bootstrap 覆盖范围与依赖

代码在每个划分内部配对采样视频，三模型分支共享样本，符合划分内配对聚类 Bootstrap。但五划分高度共享测试视频（每对共享 1164 或 1210 个视频），代码仍独立采样各划分；如果要对共同视频总体上的五划分宏平均作推断，需要联合采样视频并在各划分使用相同重复次数，保留跨划分相关性。

当前代码输出 ΔUnseen、ΔSeen 和 WSum−Power 差值；没有直接保存逐次抽样记录、ΔGap 区间或 Rej-F1/G-mIoU 区间。日志中的增益是 Bootstrap 均值，不是原测试集点估计，不能混用。例如 Moment 幂律真实 ΔUnseen 为 8.3484 pp，日志 Bootstrap 均值约 8.33 pp。

## 6. 可复现与资产边界

三个新评估脚本只打印汇总，不保存逐查询校准分数、阈值、混淆矩阵和机器可读新指标。原 `benchmark_summary.json` 与 `runs/*/predictions.npz` 仍属于原方案 A 测试排名产物，不能代表此次修正后的全量结果。

独立补算仅保存于本审计目录，未修改实验源脚本、日志或文档。`check_delivery.py` 是指标定义和数据对齐核验脚本，`audit.json` 保存原阈值下分组指标、阈值、混淆计数、逐划分 AUROC 与跨划分视频重叠数。
