## 一、 2,000 次配对视频聚类 Bootstrap 统计显著性分析

基于 2,000 次严格按视频 ID 聚类的配对重采样（Paired Video Cluster Bootstrap, Seed 3407），评估 Baseline、幂律乘积（Power-law Product, 0.65/0.85）与线性加权和（Weighted Sum, 0.5/0.5）的统计差异：

| 骨干模型 | 评估维度 | 幂律乘积 (PowerProd) | 线性加权和 (WSum) | 配对差值 (WSum − PowerProd) | 95% 置信区间 (Bootstrap) | 统计学结论 |
| :--- | :--- | :---: | :---: | :---: | :---: | :--- |
| **Moment-DETR** | **Unseen 净增益** | **+8.33 pp** | **+8.66 pp** | +0.33 pp | `[-0.45, +1.18]` | **无显著差异 (区间含 0)** |
| | **Seen 变化** | -3.40 pp | -1.48 pp | **+1.91 pp** | `[+1.57, +2.29]` | **加权和显著减少 Seen 损失** |
| **QD-DETR** | **Unseen 净增益** | **+9.41 pp** | **+9.35 pp** | -0.06 pp | `[-0.96, +0.92]` | **无显著差异 (区间含 0)** |
| | **Seen 变化** | -2.14 pp | -1.30 pp | **+0.85 pp** | `[+0.48, +1.22]` | **加权和显著减少 Seen 损失** |
| **FlashVTG** | **Unseen 净增益** | **+4.83 pp** | **+5.38 pp** | +0.55 pp | `[-0.24, +1.41]` | **无显著差异 (区间含 0)** |
| | **Seen 变化** | -5.20 pp | -2.80 pp | **+2.40 pp** | `[+2.08, +2.73]` | **加权和显著减少 Seen 损失** |

### 统计学定论：
1. **不能声称加权和在 Unseen 上反超**：在三大骨干上，加权和与幂律乘积在 Unseen 上的配对差值 95% 置信区间全部横跨 0（QD 为 `[-0.96, +0.92]`），**两者在未见语义排序能力上统计等价**。
2. **加权和显著优于幂律之处在于 Seen 保留**：加权和在 Seen AUROC 上比幂律乘积少损失 **+0.85 ~ +2.40 pp**，且置信区间严格排除 0（极显著）。加权和是一组更均衡、泛化代价更小的强基线。

## 二、 Seen 验证集阈值锁定下的真实拒绝与定位评估 (Thresholded GMR Metrics)

在各划分的 Seen 验证集（严格仅含 S+/S-）上搜索最大化 Balanced Accuracy 的二值分类阈值 $\tau^*$，冻结后应用于测试集，评估真实二值决策指标：

| 骨干模型 | 决策分支 (Arm) | 实际拒绝 F1 (Rej-F1) | 整体拒绝率 (RR) | S+ 误拒率 (S+ FRR) | U+ 误拒率 (U+ FRR) | 端到端定位 (G-mIoU@1) |
| :--- | :--- | :---: | :---: | :---: | :---: | :---: |
| **Moment-DETR** | Baseline (原始检测器) | 58.03% | 40.56% | 28.74% | 29.71% | 37.99% |
| | 幂律乘积 (PowerProd) | **59.40%** (+1.37) | 51.80% | 40.63% | 42.41% | **39.74%** (+1.75) |
| | 线性加权和 (WSum) | 57.38% (-0.65) | 40.92% | 29.40% | 28.15% | 37.74% (-0.25) |
| **QD-DETR** | Baseline (原始检测器) | 56.27% | 35.95% | 24.45% | 18.76% | 38.06% |
| | 幂律乘积 (PowerProd) | **58.93%** (+2.66) | 47.82% | 36.65% | 35.55% | **40.23%** (+2.17) |
| | 线性加权和 (WSum) | **57.76%** (+1.49) | 42.14% | 30.64% | 27.79% | **39.20%** (+1.14) |
| **FlashVTG** | Baseline (原始检测器) | 58.70% | 38.51% | 26.19% | 21.85% | 43.34% |
| | 幂律乘积 (PowerProd) | **59.41%** (+0.71) | 47.54% | 35.90% | 35.41% | **44.04%** (+0.70) |
| | 线性加权和 (WSum) | 57.13% (-1.57) | 39.67% | 27.55% | 28.01% | 42.81% (-0.53) |

### 机制与权衡深度剖析：
1. **幂律乘积提高 Rej-F1 与 G-mIoU@1**：在固定的二值决策下，幂律乘积使 Rej-F1 提高 +0.71 ~ +2.66 pp，G-mIoU@1 提高 +0.70 ~ +2.17 pp。
2. **代价是正例误拒率升高**：幂律乘积通过更激进地拒绝（RR 从 ~38% 升至 ~48%~52%）压低了反事实假阳性，但也使得正例误拒率（S+ FRR 与 U+ FRR）从 ~20%~28% 升高到 ~35%~42%。
3. **加权和决策更保守**：加权和的 RR 与误拒率几乎紧贴 Baseline（S+ FRR 仅上升 0.7~6.2 pp），但在硬阈值下 Rej-F1 与 G-mIoU 收益不及幂律乘积。

## 四、 核心学术主张收紧与边界声明

1. **放弃“幂律乘积是核心突破”**：实测证明简单线性加权和与普通乘积具备相当的排序能力，且加权和在维持 Seen 性能方面具有统计显著优势。
2. **“路由有效”为当前支持假设，而非唯一机制**：统一静态证据在混合动作与物体特征时会相互抵消，语义路由有助于为不同意图查询分配合适的时空流；但现有规则基于人工启发式构建，未来需评估统一自适应路由或语义留出。
3. **方向性特征贡献弱**：消融实验显示特征 12、13（状态转换方向）去除后性能无显著变化，文档与论文中不将其列为主要创新。
4. **明确标注共享候选边界**：当前多模态局部证据依托上游 HQ 候选窗口聚合，虽然检测器存在性得分为单骨干独立给出，但多模态证据流在局部窗口聚合时存在候选池共享。
5. **当前测试集非完全盲测**：现有 5 个划分的数据集多次用于算法设计与反思迭代，后续必须在严格隔离的新语义留出集上做完全冻结检验。
