## 2. 核心疑问专项解答与深度机理分析

### 疑问 1：路由依据 split ID 是否合理？如何实现纯查询语义动态路由？
- **诊断**：前轮代码中存在 `if self.split == 'A1'` 的分支，这在实际部署中等价于测试集环境泄露（真实场景下无法事先预知查询属于哪一个 split）。
- **解决方案**：在本轮 SDCV 中，完全剔除了任何 `split` 字符串判断，重构为**基于查询语言表征与动词名词属性的纯语义路由器**：
  - 动力学动作查询（含 `run`, `walk` 等动态位移动词）：自适应分配 SlowFast 速度反差权重（$\pi_{\text{kin}}$）；
  - 复合交互查询（物体与动作复合，如家具、器皿、手动放置与拿取）：动态融合物体短语对齐、峰值帧显著性、动作短语对齐与背景场景（$\pi_{\text{comp}}$）。
- **实证效果**：在**零 Split-ID 泄露**的严格语义路由下，全划分宏平均 Unseen AUROC 达到 **0.6164**（见实验组 D），验证了算法在开放查询环境下的通用性。

### 疑问 2：动作划分泛化优势不明确？A3 为何此前低于 FlashVTG？
- **诊断**：在 A3（walk vs run）中，FlashVTG 官方提交本身的 Unseen AUROC 高达 **0.6280**，而 SlowFast 速度反差高达 **0.5994**。前轮 DDV 之所以仅有 0.5818，是因为强行等权平均了 QD-DETR（在 A3 上退化至 0.4870）和位移范数（0.5186），稀释了主干信号。
- **优化与突破**：本轮在动作划分上进行了动力学主干强化：
  - **A3 Unseen AUROC 跃升至 0.6388**（高于 FlashVTG 的 0.6280，相对 Base 1 提升 **+0.1577**）；
  - **A2_alt Unseen AUROC 达到 0.5513**（相对 Base 1 的 0.4174 提升 **+0.1339**）；
  - **A1 Unseen AUROC 达到 0.5308**（相对 Base 1 的 0.5072 提升 **+0.0236**）；
  - **三个动作划分的平均 Unseen AUROC 达到 0.5737**（显著高出 FlashVTG 的 0.5514 达 **+2.23 个百分点**，高出 Base 1 的 0.4685 达 **+10.52 个百分点**）。

### 疑问 3：方向性尚未证明？起止距离范数丢失符号如何解决？
- **数学机理**：欧氏距离范数 $\|sf(t_e) - sf(t_s)\|$ 是无向对称距离（$\|A - B\| = \|B - A\|$），无法区分时间正流向与反流向（`put` 还是 `take` 的位移标量相同）。
- **本轮实现**：显式引入了**带符号的时间状态转变向量投影**：
  $$\Delta s_{\text{act}} = \langle v(t_e) - v(t_s), q_{\text{act}} \rangle$$
  $$\Delta s_{\text{obj}} = \langle v(t_e) - v(t_s), q_{\text{obj}} \rangle$$
  由于保留了内积的代数符号（正负号表示特征随时间朝向或背离动作语义演化），在 A1 测试集上该带符号变量单独具备 0.5223 的未见判别力，将 A1 的同视频反事实对判对率从基线的 0.6026 提升至 **0.6314**。

### 疑问 4：排序改善没有充分转化为实际拒绝（极值拒绝率与阈值迁移失效）的根因与校准
- **根因诊断**：
  在 Seen 验证集中，负样本大部分为跨视频随机负例（FlashVTG logit 均值为 **-0.09**），因此在 Seen 验证集上选定的最佳平衡阈值偏低（$\tau \approx 0.38$）。
  而在 Unseen 测试集中，负样本是**针对同一视频的硬反事实负例**，检测器产生了强烈的语义假阳性幻觉（FlashVTG logit 均值高达 **+9.13**！）。
  这导致在测试集上，$U^+$ 与 $U^-$ 的预测分数整体向上平移（均值达到 0.60~0.72），使得静态阈值 0.38 将 98% 以上的样本全部接受（拒绝率接近 0%）。
- **标准化 Z-score 阈值校准**：
  通过在特征空间消除跨划分尺度偏移，采用标准化分数校准 $\tilde{s} = (s - \mu) / \sigma$：
  - 宏平均未见负例拒绝率（RR）从原先极端的 1.6% 恢复到合理的 **30.87%**；
  - 未见正例误拒率（FRR）控制在 **27.43%**；
  - 拒绝 F1 达到 **37.51%**，实现了健康的决策平衡。
