# AC-Verifier 独立复核：宏平均 AUROC 目标初步达成，收益范围需限定

日期：2026-10-06。原实验目录：`../aligned_calibration_verifier/`。复核只写本目录，未修改原代码、特征、报告或 P1 检查点。原流水线没有保存 P0 权重和逐查询预测，因此本轮重放了原 P0 的 30 步训练；没有拟合新的研究方法。

## 结论

**按照用户明确提出的目标——Unseen AUROC 提高、Seen−Unseen Gap 缩小，且不牺牲 Seen——当前五划分的单种子宏平均结果已经初步达成。** 原报告的 AUROC、阈值、PairAcc 与三项宏平均 bootstrap 区间均可复现；本轮没有发现原 DAO 的标签完整性泄漏或坐标错误。

这是一项**幅度较小、主要由 C1 支撑的探索性改善**。不能把它表述为所有未见动作均已解决、彻底排除了所有文本分布捷径，或已经证明实际 GMR 拒绝与定位全面改善。

## 1. 核心结果全量复现

| 模型 | Mean Seen AUROC | Mean Unseen AUROC | Mean Gap |
| --- | ---: | ---: | ---: |
| HQ 缓存原始 logit 基线 | 0.751090 | 0.502727 | 0.248363 |
| 独立训练 P0，原协议重放 | 0.753452 | 0.507839 | 0.245613 |
| P1 AC-Verifier，原 checkpoint | **0.756107** | **0.518821** | **0.237286** |

P0 重放的 Unseen AUROC 与原报告五组均完全一致；Seen 指标最大误差约 7.5e-7。P1 的 AUROC、PairAcc、FRR、RR 与原报告完全一致，Seen 阈值误差为 0。

独立实现按共享测试视频成对聚类 bootstrap，联合重抽样 1,217 个视频 2,000 次，三个宏平均区间与原报告的最大差为 **0**：

| P1 − HQ 基线 | 点估计 | 视频聚类 bootstrap 95% CI |
| --- | ---: | ---: |
| Seen AUROC 增益 | +0.005017（+0.50 pp） | [+0.002471, +0.007465] |
| Unseen AUROC 增益 | **+0.016094（+1.61 pp）** | **[+0.006615, +0.026566]** |
| Gap 缩小 | **+0.011077（+1.11 pp）** | **[+0.001428, +0.021484]** |

Gap 相对原差距缩小约 **4.46%**。Unseen 从约 0.503 提高至约 0.519，仍接近随机水平，不能称为大幅解决。

P1 相对独立 P0 的 Unseen 净增益为 **+0.010982**，新增计算的 95% CI 为 **[+0.007478, +0.014980]**。因此“有超出 detector-only 适配的平均收益”有抽样证据支持，而非仅由点估计推断。P0 与 P1 初始化/训练路径不同；冻结同一个 P1 的 detector-only 对照也确认了新增证据贡献，净增益约 +0.011032，CI [+0.007658, +0.014867]。

这些是固定训练结果在当前测试视频上的区间，不包含训练种子、反复查看 U 后的设计选择和新语义留出不确定性。

基线应命名为 **HQ 缓存完整 logit 基线**。原报告的 `Baseline Fresh` 名称容易与此前的新鲜源推理或发布表舍入概率结果混淆；本轮没有重放整个原始 GMR backbone。当前比较是在同一 HQ 输入与完整 logit 精度下成立。

## 3. 特征与训练协议检查

15 份 train/val/test 缓存逐项核验：

- qid 唯一、覆盖完整，query/label/video 与发布数据相符；训练分区全部是 S+/S−。
- 五划分的 train/val/test 视频交集均为 0。
- 同一划分中相同查询跨三个子集的整句、动作、物体投影向量完全一致，差异组数为 0。
- 文本向量归一化，保存的 raw cosine 和 reference-centered cosine 与独立计算一致；cxw 转换误差为 0。
- 每组训练视频参考从原始唯一 train 视频重新计算，与缓存最大误差为 0。
- `‖q_act−q_obj‖` 标签 AUROC 在 **0.3851–0.4976**；原版完美标签通道消失。
- P1 不读取 `labels` 来形成分数，实际新增输入只有整句的两个相似度；动作/物体短语向量不参与 P1 推理。
- 代码中的 checkpoint 和阈值均用 Seen validation；P1 约 32,903 参数。

该距离探针只排除了已知模式，**不能证明“任何文本标签信道或数据措辞偏差均已彻底排除”**。相同 query 的跨视频排序和独立文本对照仍应保留。

另外，原报告把上轮动作流失败确定归因为“365 万参数导致过拟合”，证据强于原审计结论。原审计确认的是泛化落差，并未独立分离容量、优化、对齐和监督的原因。

## 4. 归因复查：新增分支有视觉贡献，但原控制命名和结论需更正

### 原置换控制打乱的是分数，不是固定 query 的视频

`train_and_eval.py` 第 210–212 行置换 `sim_cand_sent/sim_glob_sent`。由于这两个数已包含 `query−reference` 校准，置换会同时改变 query 对应项。因此它不是严格的“只换视频”控制。

本轮补做了更合适的控制：保留原 query 投影、reference、QD logit/slot/fg、候选归一化位置；按原视频成组分配不同视频 donor，配对两个成员共享同一 donor，再从 donor 帧重新裁窗并计算相似度。五次结果：

| 输入 | Mean Unseen AUROC |
| --- | ---: |
| 真实 query−video 对应 | **0.518821** |
| 固定 query，置换视频 1 | 0.508003 |
| 固定 query，置换视频 2 | 0.507109 |
| 固定 query，置换视频 3 | 0.510381 |
| 固定 query，置换视频 4 | 0.508623 |
| 固定 query，置换视频 5 | 0.507929 |

完整模型对每次控制的宏平均 Unseen 增益 CI 均排除零，例如第一次为 **[+0.006011, +0.016096]**。因此新增分支存在视频对应贡献，这一点在修正控制后仍成立。

该控制保留 QD 视频表示，不是整系统所有视觉输入的置换；作用范围是新增 CLIP 校准分支。

### “Text-Only Zero Video” 实际是 P1 自己的 detector-only

第 219–225 行将两个相似度设为 0，保留 QD 的 `orig_logits/fg_max/h_pool`；同时移除了 CLIP raw cosine 和 query-reference 两部分。因此它不是纯文本模型。

实际数值：

- 独立 P0 Mean Unseen：**0.507839351**。
- P1 关闭新增证据后 Mean Unseen：**0.507789020**。

二者接近但不相等，不是“精确回退到同一个 P0 checkpoint”。这项控制只能说明新增分支的净作用，不能单独证明所有文本捷径不存在。

### 单独分离 reference 项与 raw CLIP 项

以下都是同一 P1 checkpoint 的冻结干预，没有独立重训或依据 U 选择新方法：

| 评分方式 | Mean Unseen AUROC |
| --- | ---: |
| P1 自己的 detector-only | 0.507789 |
| detector + 仅 query-reference 项 | 0.510770 |
| detector + raw CLIP cosine，去掉 reference 项 | 0.515443 |
| 完整 P1 | **0.518821** |

完整模型比 reference-only 的净增益约 +0.008051，CI **[+0.003943, +0.012497]**，支持原视频对应在固定校准项之外的贡献。完整模型比 raw-no-reference 的增益约 +0.003378，CI **[+0.001264, +0.005407]**，支持当前权重下 reference 项改善宏平均 U 排序；但对 raw-no-reference 的 Gap 改善区间仍跨零。

因此较准确的机制结论是：“检测器适配、固定查询校准与 CLIP 视频对应共同产生平均收益”；不能说全部收益都来自视觉，或校准项毫无文本分布贡献。

### “无偏参考”没有数学保证

若每个视频全局单位向量为 `v_j`，则平均训练视频相似度为 `q·mean(v_j)`。当前实现再次归一化 `mean(v_j)`，实际减的是 `q·normalize(mean(v_j))`。缓存参考均值归一化前范数约为 0.884，两者有比例差。

这是一种合理的**固定参考校准定义**，但不能自动称为无偏的边际期望估计。该术语问题不否定已复现的效果；应明确公式并用实验比较，而不是把“无标签”当成“无偏”的证明。

## 5. AUROC 改善不等于实际 GMR 拒绝和定位已经改善

用户最初目标明确针对 AUROC；上述宏平均目标成立。若要进一步声称系统拒绝与定位全面改善，还需要阈值指标：

- Seen 选出的阈值下，A2_alt 仅拒绝 **1.28%** 的 U−，C1 仅拒绝 **7.41%** 的 U−。
- A3 的 U+ 误拒率 **42.19%**，C2_alt **55.65%**。
- 固定同一 top-foreground proposal，分别用各自 Seen-selected 阈值门控的 U+ R1@IoU0.5：

| 划分 | HQ 基线 gate R1 | P1 gate R1 |
| --- | ---: | ---: |
| A1 | 0.2129 | 0.2108 |
| A2_alt | 0.3155 | 0.3095 |
| A3 | 0.3229 | 0.3125 |
| C1 | 0.4136 | 0.4136 |
| C2_alt | 0.2348 | 0.2000 |

这是候选级门控诊断，不是完整官方多 proposal 定位评测；尚未计算并确认完整 G-mIoU。不能用它取代官方评测，也不能忽略其反映的正例拒绝代价。

## 6. 对报告建议采用的结论文字

> 在当前五个语义留出的单种子探索性评测中，AC-Verifier 相对同输入、完整 logit 的 HQ 基线，将宏平均 Unseen AUROC 从 0.5027 提高至 0.5188，将 Seen−Unseen Gap 从 0.2484 降至 0.2373，Seen AUROC 同时提高至 0.7561。成对视频聚类 bootstrap 支持该平均改善。独立 detector-only 对照和固定查询的视频置换支持新增校准分支的净贡献及视频对应作用。收益主要集中于 C1；未见动作三划分的独立退化缓解、训练种子鲁棒性和新语义留出的确认尚未建立。

应删除或收敛：“彻底排除任何文本信道”“纯文本置零”“精确回退 P0”“全部收益完全来自视觉”“已经普遍解决未见动作退化”。

## 7. 下一步最小确认工作

1. 保存并冻结当前方法、特征和代码，在新语义留出上确认；现有五组 U 已多轮查看，统计区间不能消除方法选择偏差。
2. 至少三个配对训练种子；P0/P1 detector 部分使用同一初始权重，并分别保存 checkpoint、epoch 曲线、阈值和逐查询分数。
3. 独立训练 raw-cosine/no-reference、reference-only、完整 P1，而不只做冻结干预；保留 fixed-query 视频置换与同 query 跨视频评测。
4. 对当前未解决的动作划分单独立项。先在 Seen 开发侧证明动作/时序证据的跨视频对应贡献，再进入 U；不能把 C1 外观收益当作动作泛化证据。
5. 如目标扩大到完整 GMR，补 Seen-threshold RR/FRR/Rej-F1、官方定位与 G-mIoU；不改变最初 AUROC 成功判据，但将不同结论分别陈述。
