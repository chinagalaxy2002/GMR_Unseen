# 诊断日志覆盖范围

完整机制日志来自原 baseline 诊断队列。新增三项发表协议复现单独保存原生训练、选模、早停和最终评估记录。

| 方面 | 记录内容 |
|---|---|
| 训练过程与协议 | epoch、batch、step、学习率、运行时间、seed、配置和代码哈希、选模指标、最佳轮次、连续未改善轮数、早停及报错 |
| 存在性判别与分数 | 正负样本 logit、sigmoid、原生评估分数、饱和、舍入并列、错排比例、极端反序样本 |
| 定位与候选响应 | top-1 IoU、最佳候选覆盖、激活候选数量、正样本正确响应、负样本伪响应、定位和存在判别联合结果 |
| DETR 槽位分工 | 实际 Hungarian 匹配次数、匹配归属变化、训练与固定 probe 翻转率、槽位使用分布 |
| 内部表征与注意力 | DETR 逐层 query 相似度、距离、秩、候选重叠、自/交叉注意力；Flash 时序表征、多尺度金字塔、边界、交叉注意力 |
| 损失与梯度 | 定位/分类/存在损失、正负样本损失贡献、梯度范数/余弦/冲突、裁剪前范数和裁剪系数 |
| 池化与存在头 | 槽位/时序单元贡献、正确或匹配槽位贡献占比、逐单元移除后的分数变化、ReLU 活跃率 |
| 参数更新与样本分层 | 模块逐轮参数变化、同视频正负排序、视频长度/GT 数/截断情况分层统计 |
| 泛化评估 | Seen/Unseen AUROC、实际 Rej-F1、G-mIoU@1、Seen−Unseen Gap；总体 Rej-F1/拒绝率/G-mIoU、S+/U+误拒率、样本数、视频 bootstrap 95% CI、2×2 AUROC 分解 |

记录阶段：训练 batch、每轮固定 Seen probe、每轮全量 Seen validation、选模和阈值冻结后的最终 test。昂贵的梯度、逐层表征和逐单元移除诊断在首 batch 和每 50 steps 采样；具体频率见 [完整监控口径](FULL_BASELINE_MONITORING.md)。

Moment/QD 使用 decoder query 和 Hungarian 匹配；Flash 使用时序单元和多尺度候选。负样本没有定位 GT。Rej-F1 和 G-mIoU 的子集差值依赖子集正负样本比例。

本次 GitHub 同步仅保存训练文本日志、逐轮汇总、最终指标表、选模与早停记录、必要配置和进度快照。检查点、NPZ、逐样本预测、bootstrap 数组、原始诊断数据、特征、视频、缓存和凭据不新增上传。
