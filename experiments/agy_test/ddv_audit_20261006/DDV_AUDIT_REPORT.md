# DDV 独立复验与后续实验建议

日期：2026-10-06。审计及新增控制组全部保存于本目录，原 DDV、MCV、AC 代码与产物未修改。

## 1. 是否达到了最初目标

**对“相对 QD-DETR 基线，五划分宏平均 Unseen AUROC 提高、Seen−Unseen Gap 缩小”的目标，本次结果已经达到，而且能从检查点和逐查询预测复现。**

但结论需要限定范围：目前证据支持一个使用三个检测骨干、按已知划分选择证据流的验证系统改善了宏平均表现；尚不能宣称通用的方向反事实推理已经解决，也不能宣称所有划分均缓解退化或同预算比较中完全没有 Seen 损失。

新增同预算控制表明，收益并非全由增加检测骨干解释：保持三骨干、训练预算、配对损失和 Seen 选模，去掉新增验证模块后，Unseen 为 0.5523；DDV 为 0.6134，增加 **6.11 pp**，视频聚类 Bootstrap 95% CI 为 **[4.22, 8.21] pp**。同时，DDV 相对该控制的 Seen 降低 **0.94 pp**，CI 为 **[−1.45, −0.44] pp**。因此，新增验证模块的整体效果有用，且存在 Seen/Unseen 的取舍。

本控制只训练检测器共识的三个权重；DDV 还增加了 gate 网络、fg/span 上下文与证据加权。因此，它隔离的是完整新增模块，尚未区分视觉匹配、动力学、检测器上下文及非线性容量各自的贡献。不能据此把全部增益归因到某一种新视觉特征；还应补参数量接近的 detector-only MLP 校准控制。

## 2. 实际完成的核验

- 重放全部五个保存的 DDV 检查点；与原 `predictions.npz` 最大误差为约 `1.19e-7`。主指标使用原保存分数独立重算，不把 CPU 浮点误差引入 Bootstrap。
- 核验全部 15 份缓存的 qid、视频、标签、分区、AC/MCV 拼接和动作/物体相似度。特征拼接误差为 0；训练与验证均仅包含 S+/S−；训练/验证和训练/测试视频交集均为 0。
- 检查训练三骨干缓存的 qid、标签及原始分数与输入列对应关系。Flash 使用 logit，Moment/QD 使用概率；每列在 train/val/test 中口径一致，train-only CDF 对它们归一化。因此，注释里“全部概率”不准确，但这里没有发现跨子集单位错配。
- 从原始 CLIP/SlowFast 特征独立抽查 90 行，重算 peak、velocity contrast、endpoint displacement，误差均小于 `1e-4`。这是特征文件复算，不是从原始视频重跑视觉编码器。
- 在 CPU 上新增五个独立训练的 detector-only 控制：400 epochs × 10 steps，seed 3407，相同 50% 同视频配对采样、50% 正负随机配对采样、排序损失、BCE、熵正则、AdamW、余弦调度和 Seen 验证 AUROC 选模。保留 DDV 原检测器流的 split-specific median 系数。随机数生成环境与模型参数量不同，不声称它与原 GPU DDV 使用了逐步相同的 minibatch。
- 用共享视频重采样、独立加权 AUC 算法复算 2,000 次 paired cluster Bootstrap。原报告的主要置信区间可复现；额外计算公平控制、逐划分、语义类别及 PairAcc 区间。
- 按 GMR 原论文第 3.3 节及仓库 `eval/metrics.py` 重新计算 G-mIoU，并按 qid 对齐。原 DDV 的指标实现错误，详见第 5 节。

以上检查没有发现本次缓存直接把逐样本测试标签或 GT 窗口作为新增证据输入。它们不能单独证明一切可能的泄漏都不存在，也不覆盖反复查看测试结果后的方法设计适配。

## 3. 公平比较后的结果

AUROC、Gap 和 PairAcc 使用 0–1 标度；表格为五个划分等权平均。

| 方法 | Seen | Unseen | Gap | Matched PairAcc |
|---|---:|---:|---:|---:|
| QD HQ 原始 logit，Base 1 | 0.7511 | 0.5027 | 0.2484 | 0.5181 |
| QD 发布概率，Base 2 | 0.7476 | 0.5144 | 0.2332 | **0.5294** |
| Moment 发布概率 | 0.7518 | 0.5287 | 0.2231 | 0.6009 |
| Flash 发布概率 | 0.7550 | 0.5479 | 0.2071 | 0.5358 |
| Flash 原始 logit | **0.7730** | **0.5714** | 0.2016 | 0.6140 |
| 三骨干 train-CDF 等权均值 | 0.7765 | 0.5478 | 0.2286 | 0.6076 |
| 三骨干 train-CDF 中位数 | 0.7761 | 0.5508 | 0.2254 | 0.5810 |

| DDV | **0.7684** | **0.6134** | **0.1550** | **0.6608** |

Flash 原始 logit 与发布概率的差异来源于概率饱和、舍入及并列分数。有限精度概率不是严格保序的变换，AUROC 可以改变。应同时保留官方发布口径和高精度原始口径，避免只恢复某一个骨干的原始分数。

### 3.1 主要 Bootstrap 比较

下面是 DDV 减去对照的点估计及 95% CI；Gap 缩小量定义为对照 Gap − DDV Gap。

| 对照 | Δ Unseen，pp | 95% CI，pp | Δ Seen，pp | 95% CI，pp | Gap 缩小，pp |
|---|---:|---|---:|---|---:|
| HQ QD | +11.06 | [8.89, 13.47] | +1.73 | [1.04, 2.46] | +9.34 |
| Release QD | +9.89 | [7.74, 12.20] | +2.08 | [1.39, 2.78] | +7.82 |
| Flash 原始 logit | +4.19 | [2.01, 6.49] | −0.47 | [−1.14, 0.18] | +4.66 |
| 三骨干中位数 | +6.26 | [4.36, 8.34] | −0.78 | [−1.29, −0.26] | +7.04 |

与 HQ QD 相比，宏平均 Seen 同时提高，Gap 缩小并非由降低 Seen 造成。与匹配三骨干控制相比，Gap 缩小既包含 Unseen 提升，也包含 Seen 下降，应同时呈现。

DDV Unseen 的 CI 为 **[0.5926, 0.6346]**。点估计超过 0.60；该区间包含 0.60，因此不能写“95% 置信水平下严格超过 0.60”。

Bootstrap 条件于已经训练好的单种子模型与现有测试视频，不包含训练随机性，也不能据此保证对新的语义划分具有相同增益。逐划分区间是探索性结果，没有做多重比较校正。

## 5. 报告与实现中需要修正的事项

### 5.1 G-mIoU 实现错误，已独立纠正

原 `train_and_eval.py:93` 的函数存在两个明确错误：

1. 正确拒绝的负样本，即预测和 GT 均为空，返回 0；GMR 论文规定返回 1。
2. 多个预测窗口先合成 `[最早开始, 最晚结束]` 再取最佳 GT IoU；论文规定一对一匹配和集合分母 `|P|+|G|−|M|`。

这不影响 AUROC 数字，但使报告中的 DDV G-mIoU 无法与基线 G-mIoU 比较。使用原发布候选窗口及各自 Seen 验证阈值，正确结果为：

| 模型 | Seen G-mIoU@1/@3/@5，% | Unseen G-mIoU@1/@3/@5，% |
|---|---|---|
| HQ QD | 40.97 / 29.19 / 26.83 | **24.55 / 18.58 / 17.39** |
| DDV | 41.86 / 29.69 / 27.26 | **29.25 / 23.38 / 22.20** |
| 匹配 detector-only | 42.32 / 30.80 / 28.50 | **28.66 / 23.04 / 21.91** |

额外使用 QD 保存的 `pre_exist` 候选、重新统一施加存在门控：Unseen G-mIoU@1 为 HQ **24.54%**、DDV **29.21%**，差值 +4.67 pp，CI **[3.34, 6.04] pp**。两套候选口径接近，全部查询原候选均非空；这里没有发现旧门控遗留为空导致的不可恢复候选问题。此结果评价的是固定 QD 候选加 DDV 门控，不代表 DDV 改进了定位坐标。

C1 的高 Unseen AUROC 没有转化为 G-mIoU 改善：统一 `pre_exist` 候选时，Unseen G-mIoU@1 从 17.70% 降至 16.20%。必须把运行点校准列为下一步重点。

### 5.2 路由按 split 编写，未实现所宣称的查询语义路由

`model.py:61`、`:112`、`:120` 直接使用 `split` 选择通道、权重长度和 median 系数。这是五种预先指定的结构配置，不能写成“根据查询语义动态路由”。A1、A2、A3、C1、C2 的 Seen 查询也会分别使用所在 split 的相同路由。

已知划分条件下的结果可以如实报告，但应说明允许了这种信息。要支持通用方法，应提供统一结构，或路由仅依赖 query 与 Seen 训练得到的参数。现有测试划分已在多轮实验中反复查看，当前结果可作为方法开发证据；正式“盲评”需要冻结设计后再评价未参与开发的语义划分。

### 5.3 目前特征没有直接验证方向性

`||sf_end−sf_start||` 交换端点后不变；相邻差分范数的均值丢失符号。它们描述特征变化幅度，不能单独证明 put/take 等相反方向关系。SlowFast 内部可能包含时序信息，检测器候选也依赖查询，因此这里并不推断整个系统严格时间反转不变。

需要补充有向起止状态、查询对应的方向投影，及时间反转/动作互换后的分数响应实验。当前 A1 结果没有提供方向识别突破的证据。输入中也没有音频流，报告应避免使用“视听证据”。

### 5.4 模块和训练描述应对应实际代码

- `w_obj`、`w_kin`、`w_vis` 没有进入 forward；五个模型中它们的梯度均为 `None`。实际证据加权参数是 `w_ev_split`。这不意味着物体特征没用，但不能把未参与计算的参数画成已训练的三个独立分支。
- A3 的 alpha 区间为 **[0.35, 0.60]**，其余为 [0.35, 0.55]。
- 原检查点约 400 个标量参数，训练使用预提取的 12 维证据和冻结骨干结果。400 epochs 的短耗时是验证头训练时间，不包含三骨干训练或 CLIP/SlowFast 特征提取，不能称为完整视觉系统的端到端训练总成本。
- 同视频训练对是正负样本的全组合；真正匹配负例 `source_qid` 的构造源正例仅占 **34%–38%**。因此，“50% 同视频配对”准确，“50% 全部是只改一个词的原始反事实配对”不准确。
- 给冻结模型替换为区间中点固定 alpha，Unseen 为 **0.6187**、Seen 为 **0.7538**；动态 gate 的 Unseen 反而少 0.54 pp，CI [−1.01, −0.08] pp，但 Seen 多 1.45 pp。这是推理消融，不能直接替代重训比较；它说明动态 gate 尚未被证实为 Unseen 增益来源。C1 实际 alpha 几乎恒定在 0.35015，也显示优化仍将门控推向允许的下界。

### 5.5 其他报告纠错

- Release QD 的 PairAcc 应为 **0.5294**，原代码误复用了 HQ 的 0.5181；DDV 相对它提升约 **13.14 pp**。
- 原代码没有计算 p 值。2,000 次重采样足以给出当前区间，但不能从其尾部计数直接报告 `p < 0.0001`；若另有检验，需要给出具体方法。现阶段保留 CI 结论即可。
- C1 是 `sit + bed/chair/couch` 组合；C2_alt 是 `open/close + box/cabinet` 组合，应纠正“厨房器皿与食物”等描述。
- `prepare_data.py` 依赖已有 MCV/AC 缓存；两个 DDV 命令不是从原始视频开始的完整自包含复现。应给出依赖生成顺序、三骨干检查点、外部预训练特征来源与对应哈希。

## 6. 下一步实验顺序

### 优先级 1：先确认贡献，冻结公平基线

保留本次新增的三骨干 detector-only 控制。统一报告 HQ/发布 QD、发布及高精度 Flash、Moment、简单均值/中位数，避免只与最弱单骨干比较。

在相同配对、预算和选模策略下，重训以下最小矩阵：

| 配置 | 目的 |
|---|---|
| 三骨干检测器控制 | 已补跑，作为共同起点 |
| 约 400 参数 detector-only MLP，仅用三骨干分数和 fg/span | 排除新增非线性容量与检测器上下文的贡献 |
| 控制 + CLIP，关闭 SlowFast | 判断组合语义收益是否主要来自外观 |
| 控制 + SlowFast，关闭 CLIP | 判断动力学是否独立有效 |
| 控制 + CLIP + SlowFast，统一结构 | 排除划分专用配置的贡献 |
| 统一结构，固定 alpha vs 可学习 [0,1] vs 有界 alpha | 验证门控约束的贡献与 Seen 取舍 |

所有配置从训练开始去除相应通路，不能只在完整模型测试时置零后宣称完成独立归因。另做保持 query 不变、重算 donor-video 与当前 query 相似度的视频置换诊断；直接置换预计算 query-video 相似度不是严格的视频反事实。

### 优先级 2：改善 Seen 运行点向未见查询的迁移

固定同一检查点，比较纯 Seen 验证 balanced-accuracy 阈值与只用 Seen 训练/验证的校准策略。报告 Seen/Unseen 的正负分数分布、U+ FRR、U− RR、Rej-F1 和正确 G-mIoU；补充正例 raw/gated 定位指标。

先针对 A2_alt、C1 的“几乎全接受”和 C2_alt 的“正例大量误拒”定位偏移来源。需要比较 Seen 真实原始反事实对与随机正负对的绝对分数分布。所有校准及阈值只允许使用 Seen；测试 ROC 上选择最优阈值只能作为诊断上限，不能作为最终结果。

### 优先级 3：方向架构改动建立在可测诊断上

先补正反时间顺序、动作词互换以及相同 query 跨正负视频的诊断，确认当前表示是否有方向信息。再比较现有无符号范数与有向状态变化：例如起止状态分别与查询前置/后置状态对齐，再取有符号差值；保留强度流作为速度信息。

优先采用负例 `source_qid` 精确配对的课程，与当前同视频全组合课程对照，防止把背景差异或不同事件误称为微小词汇反事实。

最后冻结结构、路由、损失、alpha 规则和校准方法，再做至少 3 个训练种子及未用于方法开发的新语义划分。验证视频置换、动作互换和时间反转的预期响应，并记录参数、特征提取、三骨干推理与验证头的完整成本。

## 7. 可用于当前汇报的结论

> 在现有五个语义划分及 Seen-only 验证选模协议下，DDV 相对 HQ QD-DETR 将宏平均 Unseen AUROC 从 0.5027 提高到 0.6134，Seen−Unseen Gap 从 0.2484 降至 0.1550。相对匹配的三骨干 detector-only 控制，新增证据带来 6.11 个百分点的 Unseen AUROC 改善，同时 Seen AUROC 降低 0.94 个百分点。收益主要体现在组合语义；A1 的退化差距仍扩大，实际拒绝阈值的迁移仍需改善。当前结果支持进一步研究该验证系统，但尚不足以证明通用的方向反事实推理能力。
