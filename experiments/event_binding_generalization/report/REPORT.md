# A/A1/B 实验记录

本文件记录 A/A1/B 阶段的设置、覆盖和测量值。数据来自 seed 3407 的训练侧 pseudo 与 seen 视图，按族报告。区间为 1000 次共同视频 bootstrap 的 95% 区间。正式 U/test 未用于模型拟合、评估或选点。

## 执行记录

- SlowFast 动作 probe：12 个；每个使用各族 S_train 的 S+ GT segment，seen 用于选轮次，held out 动词未加入训练词表。
- H/P/C/J/T：15 个小模块；每族分别拟合五个模块，seen AUROC 选 checkpoint，最多 8 轮。
- 输入：原始 CLIP 512 维与 SlowFast 2304 维；TEF 未输入小模块。冻结候选上的 map 读取规则为候选窗内 map 均值。
- 新增完整 GMR/骨干训练：0 轮。R、共享 map 完整训练、原 sit 续训：均未启动。
- 训练时并发：每张 GPU 最多 2 个任务，两张合计最多 4 个。
