定位：Technique方向的方法探索，当前只有阶段对照与待验证诊断，不主张提出新问题或已完成新方法。

| 环节 | 内容 |
| --- | --- |
| 背景 | 未见语义事件需要共同完成存在排序、接受/拒绝和定位 |
| 局限1 | 简单正则与残差容量未在GMR产生共同收益 |
| 局限2 | 双轨改变多个因素，尚不能定位存在与定位差异原因 |

| 挑战2 | 区分局部任务梯度关系与因果泛化作用 |
| 挑战3 | 以严格联合指标避免接受/拒绝与定位的指标取舍 |
| 模块A | D1视觉增量及分数可比性诊断，对应挑战1 |
| 模块B | D2梯度诊断及条件干预控制，对应挑战2 |
| 模块C | D3失败分解和双轨联合门槛，对应挑战3 |
| 拟议产出1 | 视觉利用与标尺问题的覆盖及不确定性报告（计划§4） |

检查：局限→目标通过；目标→挑战通过；挑战→诊断模块通过；模块→拟议产出通过。方法章节若将来写作：视觉必要性与标尺诊断、监督梯度关系、联合成功评估。上述均是计划结构，非已验证算法。
